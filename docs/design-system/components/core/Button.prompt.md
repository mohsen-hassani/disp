Standard clickable action button used across the app shell, forms, and dialogs.

```jsx
<Button variant="primary" onClick={save}>Save changes</Button>
```

Variants: `primary` (accent fill, main action), `secondary` (bordered, secondary action), `ghost` (no border/fill, low-emphasis), `danger` (destructive). Sizes: `md` (44px min touch target, default) and `sm` (32px, dense desktop contexts). `disabled` dims to 50% opacity.
